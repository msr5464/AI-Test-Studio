Password Recovery Options

Option 1: Contact Another Admin

If there are other admin users in the system, contact them to reset your password. They can access the User Management section in the admin panel to reset your password.

Option 2: Manual Reset

WARNING: This will DELETE ALL EXISTING USERS including all admin and customer accounts. Only use this if you are the only admin and have no other way to recover access.

Manually reset by deleting the user database file:

  1. Stop the server
  2. Delete the file: storage/users.json
  3. Restart the server
  4. A new default admin user will be created automatically
Default credentials after reset:
Username: admin
Password: admin123
Change this password immediately after login!
